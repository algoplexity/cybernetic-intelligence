# **KGRAG Analyst Co-Pilot: Zero-Knowledge Handover**

### **1. The 3 Folders in this Package**
| Folder Name | What It Is | Status |
| :--- | :--- | :--- |
| **`Code/`** | Contains the single master notebook that runs the entire project. | **READ-ONLY MASTER** |
| **`Models/`** | Contains our **custom-trained weights** for the Classifier and NER models. The notebook will automatically download the large base models. | **Our Custom IP** |
| **`Data/`** | Contains the initial input CSVs. All other data (the graph, etc.) will be generated by the notebook. | **Input Directory** |

### **2. Your First Task (Do This Today)**
This task will build all necessary assets and validate that the system works end-to-end.
1.  **Unzip this package** and upload the three folders (`Code`, `Models`, `Data`) to your project directory (e.g., Google Drive).
2.  **Open the Master Notebook:** `Code/master_pipeline.ipynb`.
3.  **Run All Cells:** From the menu, select "Runtime" -> "Run all".
4.  **Watch it work.** It will:
    *   Download large open-source base models (first run only).
    *   Download a sample of 25 PDF statements.
    *   Process them and build a Knowledge Graph.
    *   Train the final GNN Retriever model.
    *   Run two final validation queries to show you the results.

### **3. The Golden Rule**
**NEVER EDIT THE MASTER NOTEBOOK.** Before making changes, **make a personal copy**.

### **4. How to Run at Full Scale**
1.  Open your personal copy of `master_pipeline.ipynb`.
2.  In the second code cell (Stage 1), change `SAMPLE_SIZE = 25` to `SAMPLE_SIZE = -1`.
3.  Run all cells. **This will take many hours.** The script will save checkpoints, so if it times out, you can re-run the training cell to resume.
4.  **After training is complete,** you can safely delete the large `training_checkpoints/` and `optimizer.pt` files to save space.
