# **KGRAG Analyst Co-Pilot: Zero-Knowledge Handover**
"You've never seen this project. In 30 minutes, you'll own it."
**Location:** SharePoint > "Compliance Analyst Co-Pilot" Folder

### **1. The 3 Folders That Run Everything**

Your entire project lives in these three folders. **Never delete them.**

| Folder Name | What It Is | Status |
| :--- | :--- | :--- |
| **`1_Source_Code/`** | All the Python scripts (`.py` files) that make the system work. This is the "Engine Room." | **READ-ONLY MASTER** |
| **`2_Model_Assets/`** | The final, trained AI models. These are the system's "brains." They are generated by the scripts in `1_Source_Code`. | **DO NOT EDIT** |
| **`3_Data_And_Reports/`** | All the input data (CSVs), the massive Knowledge Graph, and the final output reports (e.g., `primary_analytical_report.csv`). | **Working Directory** |

### **2. The Golden Rule (Never, Ever Break This)**

**NEVER EDIT THE SCRIPTS IN THE `1_Source_Code/` FOLDER.**

This folder is our only "master" copy. Before you make *any* changes, you **MUST** do the following:

1.  **Right-click** on the `1_Source_Code/` folder.
2.  Select **"Copy to"**.
3.  Create a new folder named `1_Source_Code_MyDevBranch_YYYY-MM-DD/`.
4.  **Make all your changes in this new, personal folder.**

This is your manual "branch." If you break something in your copy, you can always go back to the original master folder.

### **3. Emergency Button (If Your Code Breaks)**

If you have made changes to a script and it no longer works, this is how you reset to a known good state:

1.  **Delete your personal code folder** (e.g., `1_Source_Code_MyDevBranch_.../`).
2.  **Make a fresh copy** of the original `1_Source_Code/` folder.
3.  Start again.

*This is our "git clone." It guarantees your scripts are perfect.*
